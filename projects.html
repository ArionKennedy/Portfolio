Database University Project: PokeBase

This project was a group project for my Databases class. We created a database that could store information about Pokemon, routes, trainers and ideal teams. Currently, it has all pokemon up to generation 9, but only trainers from generation 1. The database management system utilizes SQL, featuring a customized terminal interface to give a closer feeling to menus from the original pokemon games.
